# 115m 2.0 播放器 · 设计语言规范

本文件是 115m 2.0 播放器的**唯一视觉标准**。任何新增或修改 UI 之前必读。
目的：让每一次改动都自动落在同一套体系里，杜绝风格漂移与"越调越花"。

---

## 一、总原则

1. **克制优先**：能不做特效就不做。堆叠特效 = 廉价。
2. **材质统一**：所有浮层同一种玻璃材质，颜色只做"角色分层"。
3. **光只给交互**：常驻元素一律安静，只有悬停 / 激活才发光。
4. **中性即高级**：暗色场景下，中性炭黑底比任何带色偏的暗底都更耐看。

---

## 二、色彩系统

### 1. 底色（唯一）

- 全局玻璃底：`rgb(17, 17, 19)` 中性炭黑，按层级用不同透明度：
  - 控件外壳 / 圆键：`0.52`
  - 悬停态：`0.72 ~ 0.75`
  - 弹出菜单：`0.82`
  - 侧边抽屉：`0.96`
- 视频区：纯黑 `#000`。
- **禁止**任何带蓝调 / 暖调的暗底（旧版 `rgba(14,18,26)` 已废弃）。

### 2. 蓝色两个角色（核心规则）

| 角色 | 色值 | 出现时机 | 用在哪 |
| :--- | :--- | :--- | :--- |
| **交互极光（亮）** | `hsl(210, 100%, 70%)` | 瞬时（悬停） | 三联 / 托盘 / 菜单项 / 圆键 / 播放键 的底缘或环绕光 |
| **选中状态（暗）** | `hsl(210, 42%, 72%)` | 常驻 | 列表选中条、侧键展开、菜单对勾、面包屑悬停 |

**铁律**：悬停 = 正常亮，常驻 = 低亮。绝不让常驻元素使用全饱和蓝。

### 3. 进度蓝（数据）

- `--m115-engine-blue: #2b90ff`，**仅**用于进度条已播放段与音量填充。

### 4. 强调色（仅两种，克制使用）

- 琥珀金 `#fbbf24`：星标收藏。
- 珊瑚红 `#f87171`：危险操作（删除）。

---

## 三、材质与玻璃配方

- **统一配方**：
  `background: rgba(17,17,19,α)` + `border: 1px solid rgba(255,255,255,0.08~0.1)`
  + `backdrop-filter: blur(24px) saturate(190%)`。
- **景深三件套**：
  外投影 `0 8px 24px -4px rgba(0,0,0,0.45)`
  + inset 顶高光 `rgba(255,255,255,0.16)`
  + inset 底暗线 `rgba(0,0,0,0.3)`。
- **悬停按钮**：额外叠加 inset 内顶高光（`rgba(255,255,255,0.2)`），形成立体玻璃珠。

---

## 四、圆角阶梯（超椭圆系）

| 元素 | 圆角 |
| :--- | :--- |
| 28px 控件（返回键 / 关闭键 / 音量胶囊） | `9px` |
| 播放键（44px）/ 切集键（32px） | `34%` |
| 三联 / 托盘外壳 | `10px` |
| 外壳内键 | `8px` |
| 弹出菜单面板 | `12px` |
| 列表卡片 | `10px` |
| 微徽章（18px） | `4px` |

**禁止**：`50%` 正圆（进度条 / 音量的圆形 Thumb 除外）、`9999px` 全胶囊。

---

## 五、边框与发丝

- 边框一律 `1px`，白色 `8% ~ 12%`。
- 分割线：`1px` 渐变，两端羽化，高 `12px`，白色 `14% ~ 16%`，左右 `margin: 0 1px`。

---

## 六、间距网格

- 视口内边距：`24px`。
- 图标键间距：`8 ~ 12px`；胶囊内键间距：`4 ~ 6px`。
- 底栏上轨（进度条）与下行控制行间距：`8px`。

---

## 七、字体与图标

- 标题 `14px / 600`；按钮文字 `11 ~ 12px / 500`；时间码等宽 `tabular-nums`。
- 图标统一 lucide（`stroke`），外壳按钮描边 `1.6px`，菜单对勾 `2.2px`。
- 序号、时间码、百分比统一使用等宽字体。

---

## 八、状态与动效

- 悬停：亮度提升 + 极光或环绕环境光。
- 按压：`transform: scale(0.92 ~ 0.96)`。
- 过渡曲线：`cubic-bezier(0.16, 1, 0.3, 1)`，时长 `0.2 ~ 0.25s`。
- 空闲 `2.5s`：控制层整体平滑淡出。

---

## 九、反例（红线，禁止）

1. 禁止在**常驻**元素上使用全饱和蓝。
2. 禁止带色偏的暗底（蓝调 / 暖调）。
3. 禁止 `9999px` 全胶囊与 `50%` 正圆（Thumb 除外）。
4. 禁止给**圆形 / 超椭圆**控件套"底部地平线光"——几何不成立，应改用**环绕环境光**。
5. 禁止多源叠加发光（顶蓝光环 + 内蓝晕 + 底蓝光同时上，必然发糊）。
