# 115m 2.0 播放器 · 架构设计

本文件是 115m 2.0 播放器的**唯一架构标准**。功能实装前必读，防止把逻辑塞进视图层、重演旧版"单文件千行巨石"的覆辙。

配套文档：
- 视觉标准 -> `docs/设计语言规范.md`
- 迁移进度 -> `docs/迁移计划.md`
- 战略路线 -> `docs/迭代计划.md`
- 转码 / VIP / 115vod 接口 -> `.rules/transcode.md`（动手前必读）

---

## 一、定位与原则

- 底座：Vidstack（Web Components 无头流媒体内核）。
- 核心纪律：**UI 不碰业务，内核不依赖 UI，单文件单一职责，渐进装配**。
- 渐进策略：先让 UI 用 Mock 数据把视觉调到位，再逐层接入真实业务。

## 三、分层架构（目标结构）

四层单向流：下层不感知上层，上层只通过接口调用下层。

```
src/player/v2/
├── ui/                 # Layer 4 · 视图层（只渲染 + 派发事件）
│   ├── clean-view.ts   # 视口装配器（现状：单体，后续按职责拆分）
│   ├── theme.css       # 设计语言落地样式（见 docs/设计语言规范.md）
│   └── sheet.ts        # 弹出菜单组件（复用）
│
├── state/              # Layer 3 · 状态层（单一数据源 + 订阅）
│   ├── player-state.ts # 状态树：时间 / 时长 / 音量 / 选集中 / 清晰度 / 音轨 / 字幕 / 倍速 / 模式
│   └── store.ts        # 轻量发布订阅中心
│
├── controller/         # Layer 2 · 能力层（封装 Vidstack，屏蔽内核细节）
│   ├── player-core.ts  # 播放 / 暂停 / Seek / 速率 / 全屏 / 旋转
│   └── tracks.ts       # 音轨 / 字幕 / 清晰度 provider 切换
│
├── adapters/           # Layer 1 · 业务层（115 特权与外部交互）
│   ├── bridge.ts       # 现有 bridge-client.ts 归位
│   ├── services.ts     # 现有 stream-builder.ts 归位（解析 / 转码 / 直链）
│   ├── keyboard.ts     # 全局快捷键映射
│   └── history.ts      # 观看进度防抖持久化
│
└── ignition.ts         # 点火入口（串起各层，不做业务）
```

层间调用方向：`ui -> state -> controller -> adapters`（或 `ui` 直接读 `state`）。

---

## 四、数据流

```
用户操作 (UI 事件)
   -> store.action(...)            # 视图层只派发动作
      -> controller / adapters     # 能力层执行，业务层取数
         -> 状态更新 store.set(...)
            -> store 通知订阅者
               -> UI 重渲染 + Vidstack 同步
```

关键约束：
- **UI 层绝不发网络请求**，只派发 action、订阅 state。
- **controller 不 import 任何 UI 代码**，可独立驱动播放。
- Vidstack 的播放事件（timeupdate / ended / volumechange）由 controller 监听后写回 store，形成闭环。

## 五、状态模型（初稿）

| 分组 | 字段 |
| :--- | :--- |
| 播放 | `currentTime` `duration` `paused` `buffered` `volume` `muted` `rate` |
| 内容 | `title` `fileSize` `pickCode` `currentItem` `playlist[]` |
| 源 | `quality` `qualities[]` `audioTrack` `audioTracks[]` `subtitle` `subtitles[]` |
| 交互 | `controlsVisible` `activeSheet` `drawerOpen` `mode` `rotation` `fullscreen` |

商店接口：`get()` / `set(patch)` / `subscribe(fn)` / `action(name, payload)`。

## 七、实装路线（建议顺序）

1. **清理死代码**（drawer / sheet / topbar）。
2. **搭 `state/store` + `controller/player-core`**：先把播放 / 时间 / 音量 / 进度条跑通（功能 5/6/7）。
3. **接 `adapters/keyboard` + 全屏**（功能 16 + 快捷键）。
4. **接播放列表数据与切集**（功能 8/9/15），打通上一集 / 下一集。
5. **接清晰度 / 音轨 / 字幕 / 倍速**（功能 11/12/13/14），每项 `openSheet` 接真实数据。
6. **接 115 文件操作与收藏**（功能 1/2/3/4）。
7. **接历史记录**（功能 18）。
8. **补测试**，对齐项目健康基线。

原则：**一次只接一项，接完即验，绝不混杂**。
