# 115m 2.0 大图查看器重铸规范 (PhotoSwipe v5)

> 💡 **核心定位**：淘汰旧版手写缩放拖拽矩阵与阻尼数学轮子，采用工业级轻量开源引擎 **PhotoSwipe v5**，全面对齐 115m 2.0 中性炭黑晶体毛玻璃设计语言。

---

## 一、设计语言统一（对齐播放器规范）

1. **统一中性炭黑底色**：
   - 遮罩背底：`rgba(17, 17, 19, 0.94)`，纯正炭黑，杜绝蓝调与暖调杂色。
   - 浮层外壳：`rgba(17, 17, 19, 0.82)` + `backdrop-filter: blur(24px) saturate(190%)`。
   - 发丝微高光：`border: 1px solid rgba(255, 255, 255, 0.1)` + 顶发丝 `inset 0 1px 0 0 rgba(255, 255, 255, 0.18)`。
2. **两蓝角色铁律**：
   - **交互极光（亮）**：`hsl(210, 100%, 70%)`，仅用于按钮、微卡片项悬停时的底缘瞬时光效。
   - **选中状态（暗）**：`hsl(210, 42%, 72%)`，用于底部缩略图当前高亮外框，保持常驻安静。
   - **危险色**：珊瑚红 `#f87171`，仅用于删除操作。
3. **圆角阶梯**：
   - 工具栏按键：`8px` 超椭圆。
   - 缩略图卡片：`6px` 圆角。
   - 缩放倍率微徽章：`4px`。

## 二、16 项功能落位与 100% 还原映射

| # | 功能项 | 落位层 | 验收与交互标准 |
| :---: | :--- | :--- | :--- |
| 1 | **全屏沉浸灯箱** | PhotoSwipe Root | 点击列表图片即刻唤起，点击背景空白区域退出 |
| 2 | **原图直连映射** | Data Resolver | 缩略图 URL 自动转 `_0` 原图直连，清晰秒出 |
| 3 | **平滑秒出图 + Loading 兜底** | UI Feedback | 无阻塞预载门控，超时 120ms 后展示优雅 Loading |
| 4 | **相邻图片预加载** | Preloader | 自动预载当前图前后各 2 张原图，翻页零等待 |
| 5 | **文件名与当前序号** | Toolbar Meta | 顶部左侧展示 `文件名 · 当前序号 / 总数`，过长省略 |
| 6 | **缩放倍率微徽章** | Toolbar Action | 实时显示当前缩放百分比；点击在自适应与 200% 间切换 |
| 7 | **可拖拽状态提示** | Toolbar Meta | 放大超出视口时，显示轻量「可拖动」指示 |
| 8 | **独立关闭按钮** | Toolbar Action | 右上角 `X` 按钮，带悬停极光与按压微动效 |
| 9 | **左右导航箭头** | Navigation | 屏幕两侧悬浮翻页箭头，循环切换上一张 / 下一张 |
| 10 | **滚轮双模智能手势** | Wheel Adapter | **1x 状态**：滚轮上下直接平滑切图；**放大状态**：以光标为中心平滑缩放 |
| 11 | **双击缩放** | PhotoSwipe Core | 双击图片以指针位置为中心在适应屏幕与放大之间切换 |
| 12 | **惯性拖拽与物理回弹** | PhotoSwipe Core | 享受 PhotoSwipe 工业级阻尼手势与平滑回弹算法 |
| 13 | **键盘操控闭环** | Keyboard Handler | `Esc` 退出、`←` / `→` 左右切图，输入框焦点时不误触 |
| 14 | **网盘直接删除联动** | 115 API Bridge | 呼出后台 `DELETE_FILE`：移除页面卡片 + 自动切下一集 + Toast 反馈 |
| 15 | **底部缩略图胶卷条** | Filmstrip UI | 底部常驻缩略图导航，支持滚轮滚动，当前项平滑居中 |
| 16 | **缩略图折叠 / 展开** | Filmstrip Toggle | 独立折叠开关，一键收展底部胶卷条以留出最大视口 |

## 三、重构实施四步路线

1. **Step 1 · 依赖与基座集成**：
   - 安装 `photoswipe` 现代依赖；
   - 创建 `src/content/core/photoswipe-viewer.ts` 纯净适配器。
2. **Step 2 · UI 与设计语言落地**：
   - 提取并重构 `media-wall-images.css` 中的看图器样式；
   - 注入中性炭黑晶体毛玻璃顶栏、缩略图胶卷条与指示徽章。
3. **Step 3 · 业务与交互深度集成**：
   - 接入 115 删除联动、原图下载、滚轮切图与缩略图双向联动。
4. **Step 4 · 清理废弃手写轮子与验证闭环**：
   - 移除 `viewer-wheel.ts`、`viewer-transform.ts` 废弃手写数学公式及单测；
   - 确保 `pnpm test` 与 `pnpm build` 全绿。
