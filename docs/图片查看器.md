## 一、分层架构设计 (Architecture)

```text
src/content/viewer/
├── state/                   # Layer 1 · 单一状态层 (Single Source of Truth)
│   ├── viewer-store.ts      # 响应式发布订阅中心 (isOpen, items, index, zoom, pan, filmstrip)
│   └── viewer-store.test.ts # 状态流转单元测试
│
├── engine/                  # Layer 2 · 物理手势与自适应引擎
│   ├── gesture-engine.ts    # 纯函数自适应计算 (缩放吸附、物理拖拽边界限制、滚轮手势决策)
│   └── gesture-engine.test.ts
│
├── ui/                      # Layer 3 · 纯组件视图层 (各司其职，无状态杂糅)
│   ├── toolbar.ts           # 顶栏 (文件名、序号、缩放微徽章、独立右上角关闭按键)
│   ├── stage.ts             # 主舞台 (Flexbox 纯净自适应居中、双击平滑缩放、左右翻页导航)
│   ├── filmstrip.ts         # 底部胶卷条 (缩略图水平轴、发丝微光感应手柄、当前项自动居中)

└── index.ts                 # Layer 4 · 查看器装配中枢 (Orchestrator)
    ├── createImageViewer    # 穿透挂载顶级视口 window.top.document.body (真全屏、无滚动条、随窗口任意缩放)
    └── index.test.ts        # 整体装配集成测试
```

## 二、关键技术破局点

1. **顶级视口提升（解决窗口缩小被 iframe 截断、右侧出现滚动条）**：
   - 通过 `resolveViewerRootDoc` 穿透挂载至最顶层的真实浏览器窗口 `window.top.document.body`；
   - 彻底摆脱 115 网盘局部 iframe 内部写死 `min-width: 980px` 的限制；
   - 无论浏览器窗口缩窄到多小，查看器严格响应式居中，右上角关闭按钮永远常驻，右下角删除按钮绝不溢出。
2. **纯净 Flex 几何居中（解决图片靠左偏斜）**：
   - 废弃老旧的 `position: absolute; left: 50%; transform: translate(-50%, -50%)`；
   - 采用现代标准弹性视口：图片自然 `object-fit: contain` 居中，窗口改变大小时毫秒级自适应重排。
3. **底部展开 84px 净空安全区（解决大图被胶卷条遮挡）**：
   - 底部胶卷条展开时，主视口底部留足 `padding-bottom: 84px` 净空；
   - 长图、宽图在胶卷条上方自适应排布，绝对不被胶卷条遮挡任何像素；
   - 胶卷条收起时，视口平滑还原至满屏。
4. **滚轮自适应与双击往返**：
   - 1x 状态下滚轮上下滑动为**平滑切图**；
   - 双击放大或微徽章放大后，滚轮自动转为**以指针为中心的平滑缩放**；
   - 缩小回接近 1x 时自动吸附归位，后续滚轮立即无缝恢复为切图模式；
   - 再次双击精准恢复 1x。
