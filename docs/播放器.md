# 第二部分 · 设计语言

## 一、总原则

1. **克制优先**：能不做特效就不做，堆叠特效等于廉价。
2. **材质统一**：所有浮层同一种玻璃材质，颜色只做"角色分层"。
3. **光只给交互**：常驻元素一律安静，只有悬停 / 激活才发光。
4. **中性即高级**：暗色场景下，中性炭黑底比任何带色偏的暗底都耐看。

## 二、色彩系统

### 1. 底色（唯一）

- 全局玻璃底：`rgb(17, 17, 19)` 中性炭黑，按层级用不同透明度：
  - 控件外壳 / 圆键：`0.52`
  - 悬停态：`0.72 ~ 0.75`
  - 弹出菜单：`0.82`
  - 侧边抽屉：`0.96`
- 视频区：纯黑 `#000`。
- **禁止**任何带蓝调 / 暖调的暗底（旧版 `rgba(14,18,26)` 已废弃）。

### 2. 蓝色两个角色（核心规则）

| 角色 | 色值 | 出现时机 | 用在哪 |
| :--- | :--- | :--- | :--- |
| **交互极光（亮）** | `hsl(210, 100%, 70%)` | 瞬时（悬停） | 三联 / 托盘 / 菜单项 / 圆键 / 播放键 的底缘或环绕光 |
| **选中状态（暗）** | `hsl(210, 42%, 72%)` | 常驻 | 列表选中条、侧键展开、菜单对勾、面包屑悬停 |

**铁律**：悬停 = 正常亮，常驻 = 低亮。绝不让常驻元素使用全饱和蓝。

### 3. 进度蓝（数据）

- `--m115-engine-blue: #2b90ff`，**仅**用于进度条已播放段与音量填充。

### 4. 强调色（仅两种，克制使用）

- 琥珀金 `#fbbf24`：星标收藏。
- 珊瑚红 `#f87171`：危险操作（删除）。

## 三、材质与玻璃配方

- **统一配方**：`background: rgba(17,17,19,α)` + `border: 1px solid rgba(255,255,255,0.08~0.1)` + `backdrop-filter: blur(24px) saturate(190%)`。
- **景深三件套**：外投影 `0 8px 24px -4px rgba(0,0,0,0.45)` + inset 顶高光 `rgba(255,255,255,0.16)` + inset 底暗线 `rgba(0,0,0,0.3)`。
- **悬停按钮**：额外叠加 inset 内顶高光（`rgba(255,255,255,0.2)`），形成立体玻璃珠。

## 四、圆角阶梯（超椭圆系）

| 元素 | 圆角 |
| :--- | :--- |
| 28px 控件（返回键 / 关闭键 / 音量胶囊） | `9px` |
| 播放键（44px）/ 切集键（32px） | `34%` |
| 三联 / 托盘外壳 | `10px` |
| 外壳内键 | `8px` |
| 弹出菜单面板 | `12px` |
| 列表卡片 | `10px` |
| 微徽章（18px） | `4px` |

**禁止**：`50%` 正圆（进度条 / 音量的圆形 Thumb 除外）、`9999px` 全胶囊。

## 五、边框与发丝

- 边框一律 `1px`，白色 `8% ~ 12%`。
- 分割线：`1px` 渐变，两端羽化，高 `12px`，白色 `14% ~ 16%`，左右 `margin: 0 1px`。

## 六、间距网格

- 视口内边距：`24px`。
- 图标键间距：`8 ~ 12px`；胶囊内键间距：`4 ~ 6px`。
- 底栏上轨（进度条）与下行控制行间距：`8px`。

## 七、字体与图标

- 标题 `14px / 600`；按钮文字 `11 ~ 12px / 500`；时间码等宽 `tabular-nums`。
- 图标统一 lucide（`stroke`），外壳按钮描边 `1.6px`，菜单对勾 `2.2px`。
- 序号、时间码、百分比统一使用等宽字体。

## 八、状态与动效

- 悬停：亮度提升 + 极光或环绕环境光。
- 按压：`transform: scale(0.92 ~ 0.96)`。
- 过渡曲线：`cubic-bezier(0.16, 1, 0.3, 1)`，时长 `0.2 ~ 0.25s`。
- 空闲 `2.5s`：控制层整体平滑淡出。

## 九、反例（红线，禁止）

1. 禁止在**常驻**元素上使用全饱和蓝。
2. 禁止带色偏的暗底（蓝调 / 暖调）。
3. 禁止 `9999px` 全胶囊与 `50%` 正圆（Thumb 除外）。
4. 禁止给**圆形 / 超椭圆**控件套"底部地平线光"——几何不成立，应改用**环绕环境光**。
5. 禁止多源叠加发光（顶蓝光环 + 内蓝晕 + 底蓝光同时上，必然发糊）。

# 第三部分 · 架构设计

## 一、原则

- 底座：Vidstack。
- 核心纪律：**UI 不碰业务，内核不依赖 UI，单文件单一职责，渐进装配**。
- 渐进策略：先让 UI 用 Mock 数据把视觉调到位，再逐层接入真实业务。

## 二、分层架构（目标结构）

四层单向流：下层不感知上层，上层只通过接口调用下层。

```
src/player/v2/
├── ui/                 # Layer 4 · 视图层（只渲染 + 派发事件）
│   ├── clean-view.ts   # 视口装配器（现状：单体，后续按职责拆分）
│   ├── sheet.ts        # 弹出菜单组件（复用）
│   └── theme.css       # 设计语言落地样式
│
├── state/              # Layer 3 · 状态层（单一数据源 + 订阅）
│   ├── player-state.ts # 时间 / 时长 / 音量 / 选集中 / 清晰度 / 音轨 / 字幕 / 倍速 / 模式
│   └── store.ts        # 轻量发布订阅中心
│
├── controller/         # Layer 2 · 能力层（封装 Vidstack，屏蔽内核细节）
│   ├── player-core.ts  # 播放 / 暂停 / Seek / 速率 / 全屏 / 旋转
│   └── tracks.ts       # 音轨 / 字幕 / 清晰度 provider 切换
│
├── adapters/           # Layer 1 · 业务层（115 特权与外部交互）
│   ├── bridge.ts       # 现有 bridge-client.ts 归位
│   ├── services.ts     # 现有 stream-builder.ts 归位（解析 / 转码 / 直链）
│   ├── keyboard.ts     # 全局快捷键映射
│   └── history.ts      # 观看进度防抖持久化
│
└── ignition.ts         # 点火入口（串起各层，不做业务）
```

层间调用方向：`ui -> state -> controller -> adapters`（`ui` 亦可直接读 `state`）。

## 三、数据流

```
用户操作 (UI 事件)
   -> store.action(...)            # 视图层只派发动作
      -> controller / adapters     # 能力层执行，业务层取数
         -> 状态更新 store.set(...)
            -> store 通知订阅者
               -> UI 重渲染 + Vidstack 同步
```

关键约束：
- **UI 层绝不发网络请求**，只派发 action、订阅 state。
- **controller 不 import 任何 UI 代码**，可独立驱动播放。
- Vidstack 的播放事件（timeupdate / ended / volumechange）由 controller 监听后写回 store，形成闭环。

## 四、状态模型（初稿）

| 分组 | 字段 |
| :--- | :--- |
| 播放 | `currentTime` `duration` `paused` `buffered` `volume` `muted` `rate` |
| 内容 | `title` `fileSize` `pickCode` `currentItem` `playlist[]` |
| 源 | `quality` `qualities[]` `audioTrack` `audioTracks[]` `subtitle` `subtitles[]` |
| 交互 | `controlsVisible` `activeSheet` `drawerOpen` `mode` `rotation` `fullscreen` |

商店接口：`get()` / `set(patch)` / `subscribe(fn)` / `action(name, payload)`。

## 六、实装路线（建议顺序）

1. **清理死代码**（drawer / sheet / topbar）。
2. **搭 `state/store` + `controller/player-core`**：先把播放 / 时间 / 音量 / 进度条跑通（功能 5/6/7）。
3. **接 `adapters/keyboard` + 全屏**（功能 16 + 快捷键）。
4. **接播放列表数据与切集**（功能 8/9/15），打通上一集 / 下一集。
5. **接清晰度 / 音轨 / 字幕 / 倍速**（功能 11/12/13/14），每项 `openSheet` 接真实数据。
6. **接进度条悬停预览**（功能 23，复用旧采样策略与状态机）。
7. **接 115 文件操作与收藏**（功能 1/2/3/4）。
8. **接历史记录**（功能 18）。
9. **补测试**，对齐项目健康基线。

原则：**一次只接一项，接完即验，绝不混杂**。
