# 播放器规则

## UI 与样式规范

- **禁止行内样式**：禁止在 TS/JS 中使用 `style.cssText` 裸写复杂的布局和颜色样式。所有 UI 组件的样式必须写入 `src/player/core/css/` 对应的 CSS 文件中。
- **复用 CSS 变量**：必须优先使用 `player-skin.css` 中定义的 `--m115-*` 变量，保持尺寸、圆角、颜色和阴影的全局统一。
- **毛玻璃与深色调**：所有悬浮面板、下拉菜单、侧边栏必须统一使用深色半透明背景（`rgba(24, 26, 30, 0.96)`）并配合毛玻璃效果（`backdrop-filter: blur(16px)`）。
- **PC 端交互体验**：
  - 按钮和列表项必须有平滑的 Hover 态过渡（`.15s` 或 `.16s`）。
  - 滚动条必须使用定制的半透明样式，禁止出现系统默认滚动条。
- **层级管理**：新增悬浮元素时，必须在 `ui-layer.ts` 中定义其 `z-index`，并在 `ui-layer.css` 中统一声明，禁止在业务样式中随意编写 `z-index`。

## 架构与逻辑规范

- **模块化拆分**：优先复用 `src/player/core/*` 模块，不把逻辑塞回大文件。
- **职责划分**：修改前需明确区分是 UI 问题、状态问题、播放源问题还是消息问题。
- **小步迭代**：如果只是播放器样式或页面结构小改，保持小改，不要误扩大到整条播放器链路重构。
- **连续排错**：连续两次补丁仍不稳时，回到底层设计重看。
