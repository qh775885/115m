# 115m

`115m` 是一个为 115 网盘打造的开源 Chrome 前端增强扩展，旨在优化文件浏览排版、图片查看体验以及沉浸式视频播放。

> 💡 **特别说明**：本项目为纯前端交互增强工具，所有功能均基于用户自身已有的 115 账号权限运行，**不包含任何越权、破解或绕过付费机制的功能**。

---

## 核心功能

### 📁 浏览与交互增强

- **文件夹封面卡片**：列表页智能提取并展示媒体封面，查找目录更直观
- **图片聚合与预览**：列表页图片缩略图直接浏览，告别逐个点开
- **视频悬浮预览图**：鼠标悬停即刻预览视频关键帧内容
- **增强型图片查看器**：集成底部缩略图导航栏、鼠标滚轮平滑切图/缩放、快捷删除
- **左侧导航栏自定义**：支持按需隐藏/显示模块，打造纯净导航体验
- **VIP 转码快捷加速**：针对已具有 115 官方 VIP 权益的用户，在文件列表预览区提供一键提交加速按钮，省去反复点进播放器的繁琐步骤，支持同目录批量提交与排队状态展示
- **智能一键解压**：调用网盘官方云端解压能力，支持一键解压至同名目录、多选批量智能解压（遇密自动跳过并汇总反馈）

### 🎬 沉浸式视频播放（参考 115master 思路并深度重构）

- **独立沉浸式播放器**：点击视频直接调起大屏独立播放器，沉浸无干扰
- **智能画质策略**：优先保障最佳播放体验（原画直连无损播放），网络或环境异常时自动平滑回退至 HLS 原画转码流
- **画质记忆与切换**：支持多种清晰度手动切换，并记住个人画质偏好
- **字幕自动挂载**：自动关联同目录同名/外挂字幕，支持内嵌渲染与快速切换
- **跨端进度记忆**：播放进度实时服务端同步，多端断点续播
- **播放内文件管理**：播放中无需返回列表即可对当前视频进行目录移动，并实时同步更新列表
- **外置下载联动**：提取当前登录用户权限范围内的文件直链，方便调用 IDM、Aria2 等外部下载器

## 安装与使用

本项目未上架 Chrome 扩展商店，建议通过 Chrome 开发者模式加载使用：

### 方式一：下载预编译版本（推荐普通用户）

1. 前往本项目的 [Releases 页面](../../releases) 下载最新版本的 zip 压缩包
2. 将 zip 解压至本地固定目录（请勿解压在临时目录，后续使用需保持该路径存在）
3. 在 Chrome 浏览器地址栏输入并打开：`chrome://extensions/`
4. 打开页面右上角的 **「开发者模式」** 开关
5. 点击左上角的 **「加载已解压的扩展程序」**
6. 选择刚才解压出的扩展文件夹即可完成安装

> 💡 **版本更新**：下载新版 zip 解压覆盖原文件夹，随后在 `chrome://extensions/` 对应扩展卡片点击「重新加载」即可。

### 方式二：源码自行构建

```bash
# 安装依赖 (推荐 pnpm)
pnpm install

# 编译打包 Chrome MV3 产物
pnpm build
```
编译完成后，按上述步骤加载项目根目录下的 `dist/chrome-mv3` 文件夹即可。

## 权限说明

本项目严格遵循权限最小化原则，申请的浏览器权限仅服务于核心功能：

| 权限 | 用途说明 |
|---|---|
| `storage` / `unlimitedStorage` | 仅在浏览器本地保存用户偏好设置（如播放画质偏好）与缩略图本地缓存 |
| `cookies` | 维持与 115 网页端相同的登录态，以发起正常的媒体请求，绝不外发任何第三方 |
| `downloads` | 用于将提取的直链交给浏览器下载管理器下载 |
| `scripting` / `webNavigation` / `tabs` | 仅在 115 域名内注入 UI 增强组件并监听网盘路由状态变更 |
